# CSS Layout Challenges

Classic layout problems solved with plain HTML and CSS — no frameworks.
Each exercise is a self-contained static page: open `index.html` directly
or run `npm start` (serves the folder) to view it.

## Structure

```
css-layout-challenges/
└── holy-grail/
```

## Exercises

| Exercise     | Description                                                          |
| ------------ | ---------------------------------------------------------------------|
| `holy-grail` | Full-height header/footer with fixed-width nav/aside and fluid main  |
